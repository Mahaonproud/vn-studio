# VN Studio — редактор визуальных новелл (Windows / Linux)

Вы пишете диалоги в удобном редакторе, а программа сама создаёт файлы для Ren'Py.

## Запуск

Нужен Python 3.9 или новее (python.org; на Windows при установке отметьте «Add Python to PATH»).

* **Windows:** дважды щёлкните `run.bat`.
* **Linux:** в терминале `./run.sh`.
  Если окно не открывается с ошибкой про `xcb`, выполните: `sudo apt install libxcb-cursor0`.

При первом запуске скрипт сам установит PySide6 и pyspellchecker (нужен интернет, 1–2 минуты).

## Как пользоваться

1. **Новый проект** → введите название.
2. Вкладка **Библиотека**: «Загрузить всё из папки…» (в папке подпапки `фоны`, `эффекты`, `музыка`,
   `загрузочные`, `экраны`, `персонажи`; у персонажа своя подпапка, имя файла = эмоция).
   Позже добавляйте ещё кнопкой «Добавить ещё…». Встроенные эффекты (виньетка, кровавые брызги, зерно,
   красный оттенок, затемнение, тряска, вспышка) создаются автоматически.
3. Вкладка **Сценарий**: «Новый диалог» → фон, музыка, персонаж → пишите фразы, «Далее» (Ctrl+Enter).
   Кнопки под превью: фон, музыка, персонаж/эмоция, убрать персонажа, эффект, убрать эффект,
   варианты ответа (до 4), конец игры. Кто говорит — выбирается кнопкой с именем над полем текста.
4. **Варианты ответа:** у каждого ответа своя ветка (список слева). Если ветки сходятся: откройте одну,
   нажмите «Конечный для всех», затем в остальных — «Связать с конечным…» (или в конечной —
   «Связать остальные ответы сюда»).
5. **Меню игры:** кнопки перетаскиваются мышкой; фон, музыка, загрузочные экраны, эффекты.
6. **Оформление:** цвет, прозрачность, размер, расстояние между буквами, свой шрифт.
7. **Сохранить проект** (Ctrl+S) — сохраняет проект и сразу пишет код Ren'Py в
   `<папка проекта>/renpy_export/game`.
8. Вкладка **Проверка и экспорт** → «Экспортировать в мой проект Ren'Py…» → выберите папку проекта Ren'Py
   (где лежит `game`). Затем запустите проект в Ren'Py.

Проекты лежат в папке `VNStudio Projects` в вашей домашней папке (меняется в настройках).

## Орфография

Подчёркивает ошибки красной волной. Правый щелчок — варианты исправления; под полем — быстрые кнопки
«заменить» и «оставить». Нужен пакет `pyspellchecker` (ставится скриптом запуска).

## Что экспорт делает с проектом Ren'Py

Заменяет `script.rpy`, добавляет `vn_setup.rpy`, `vn_menu.rpy` и папку `vn_assets`. Остальное не трогает.
Если Ren'Py пишет, что экран `main_menu` определён дважды, удалите блок `screen main_menu():`
из `screens.rpy`.
